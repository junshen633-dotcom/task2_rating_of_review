# 实验设计与假设

## 研究结论与优先级

1. 全量规范化文本匹配覆盖838/10000测试行，其中632行的匹配组存在标签冲突。测试(user,prod)匹配0。不能以“相同文本标签标准差为0”为事实，也不能把近邻匹配成绩称为理论上界。
2. 星级标题条件标签分布约为T=0.75I+0.05J。若标题反映潜在星级、噪声独立且测试同分布，观察标签的条件噪声RMSE下限估计约1.068。这是有条件模型推论，不是已证明的真实下限。榜首0.45提示需要检验标签机制/评估分布，不能证明检索或作弊。
3. 原始同一holdout反复选模型和拟合收缩后，已经是开发集，不能再称独立测试。s=0.34也不代表66%预测是噪声。不同论文数据划分的RMSE不能直接比较。
4. 新协议固定80%训练、10%校准、10%最终评估。真实评论指纹分组，不含rating。统计特征5折交叉拟合，连全局先验也排除本折。模型输入保留完整标题及正文，不使用百万级实体嵌入。

## 最小实验矩阵（先顺序运行前三组）

|实验|损失|统计特征|回答的问题|
|---|---|---|---|
|E1|MSE|关闭|修复文本输入后的回归参考|
|E2|普通5分类CE|关闭|概率期望是否优于标量回归|
|E3|前向修正CE|关闭|显式噪声假设是否改善校准RMSE|
|E4|前三组最佳损失|开启OOF统计|实体历史是否提供稳定增益|

E3定义q=softmax(logits)，T行是潜在类、列是观察类，q_obs=qT，训练损失-log(q_obs[y])。同时输出观察评分期望和潜在评分期望。T只从训练集星级标题估计；标题是代理而非认证干净标签，假设可能不成立。普通CE/MSE的逆变换也只能作为假设候选。不要自动覆盖原始标签，不要按公开榜分数密集调参。

仅根据cal选择配置、早停及收缩。最终选定1-2个模型后才读取eval。报告观察标签RMSE/MAE；标题代理评分单列且说明标题也是输入，不能当独立干净标签测试。后处理的逆噪声风险估计同样依赖T正确及类条件噪声假设。

停止规则：若E3较E2无改善，不扩大噪声模型；若E4不改善，保持text-only。若资源允许，对胜出配置再跑seed43，稳定收益才进入最终候选。先测一轮耗时，以剩余SLURM墙钟决定是否继续，避免提交截止前才开始全量训练。HF预训练骨干仅在课程允许外部权重且模型已下载时尝试，不是本包默认依赖。
