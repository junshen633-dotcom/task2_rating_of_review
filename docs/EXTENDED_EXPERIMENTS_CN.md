# 后续实验预注册 — 2026-11-13

基准：E4_seed43 的 latent_hypothesis.csv，用户提供的公开榜 RMSE=0.54546；同模型 observed_calibrated=0.70392。公开榜成绩仅作为目标机制证据，不用于搜索融合权重。

1. 既有模型固定等权集成：E4 seed42/43；E3/E4 x seed42/43 四模型作为互补性对照。以 id 对齐，不能按文件行号盲目平均。
2. E4 seed43 从头重放 8 轮，前三轮 1e-3；第4–5轮 5e-4，第6–7轮2.5e-4，第8轮1.25e-4。旧 checkpoint 不含优化器状态，不声称完整恢复。长度与后期学习率共同变化；不把提升单独归因于训练轮数。
3. 保留每轮 checkpoint。best.pt 仍按观察 RMSE 选；best_latent.pt 按 cal 的噪声修正潜在 MSE 选。后者依赖固定训练集 T 假设，保留前者用于对照。
4. 额外固定候选：长训练潜在最优单模型、该模型与旧 E4 seed42 等权融合。不搜索融合权重。最终推荐仅根据 cal，eval 作为已用过的保留基准报告，不视为新盲测，也不据它调参。
5. 同时报观察 RMSE、潜在输出对带噪标签的 RMSE、修正潜在 MSE，以及成对差异。行级标准误不涵盖分组依赖、T估计误差和选择偏差，不能当作无条件显著性保证。
6. 输出新提交文件并检查 10000 行、id 唯一与模板顺序一致、rating 有限且在 [1,5]。保留原模型、原提交和元数据。仍使用80%训练分区，不进行100%重训练。
